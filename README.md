# Shorashim · Lashon HaKodesh

Aplicación web para aprender los shorashim del Jumash (181 términos), inspirada en Quizlet.

## Modos

- **Lista** — todos los términos con buscador (hebreo, inglés, español o francés) y favoritos.
- **Fichas** — tarjetas que se voltean, con seguimiento de "lo sé / aún aprendiendo".
- **Aprender** — rondas de opción múltiple con repaso automático de los términos más fallados.
- **Examen** — test configurable con corrección y puntuación.

Idiomas de la interfaz y de las traducciones: español, inglés y francés.
El progreso se guarda en el navegador de cada usuario (localStorage).

## Desarrollo

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # genera dist/
```
